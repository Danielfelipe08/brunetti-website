# Brunetti Odontologia — Page Specifications

## 1. Objetivo deste documento

Este documento define a estrutura funcional e de conteúdo das principais páginas do site da Brunetti Odontologia.

Ele deverá orientar:

- wireframes;
- prototipação;
- design de interface;
- criação de componentes;
- seleção de fotos e vídeos;
- copywriting;
- desenvolvimento frontend;
- implementação de responsividade;
- revisão por agentes de IA.

Este documento não define ainda o design visual final.

A aparência deverá respeitar:

- `01-project-brief.md`
- `02-brand-guidelines.md`
- `03-target-audience.md`
- `04-sitemap.md`
- posteriormente `06-design-system.md`

---

# 2. Regra geral para todas as páginas

Toda página deverá possuir pelo menos uma função clara:

- apresentar;
- explicar;
- gerar confiança;
- converter.

Evitar páginas ou seções criadas apenas para preencher espaço.

---

# 3. Prioridade de conversão

CTA primário global:

**WhatsApp**

CTA secundário:

- conhecer tratamentos;
- conhecer a clínica;
- explorar tecnologia;
- Instagram;
- localização.

O site deve sempre permitir conversão sem interromper a experiência visual.

# 41. Comportamento mobile

Todas as páginas deverão ser especificadas também para mobile.

Princípios:

- Hero mais curto;
- texto reduzido;
- imagens reposicionadas;
- vídeos otimizados;
- CTA acessível;
- navegação simples;
- nenhuma dependência de hover;
- performance prioritária.

---

# 42. Animações

Aplicar apenas quando ajudarem a experiência.

Direção:

- fade;
- reveal;
- mask reveal;
- scroll suave;
- deslocamentos discretos;
- parallax leve.

Evitar:

- animações constantes;
- bounce;
- zoom excessivo;
- elementos girando;
- interface chamativa.

---

# 43. Prioridade de assets

Sempre seguir:

```text
1. Material real da Brunetti

2. Novo conteúdo produzido especificamente para o site

3. Material institucional existente

4. Elementos gráficos abstratos

5. Conteúdo gerado por IA apenas quando realmente necessário
```

Não utilizar IA para substituir um asset real disponível.

---

# 44. Tratamento de texto

Regra geral:

```text
Headline
+
1 pequeno parágrafo
+
imagem
+
ação
```

Evitar blocos extensos.

Nas páginas de tratamento, textos maiores poderão existir para SEO, mas deverão ser divididos visualmente.

# 52. Performance

Especial atenção a:

- vídeos;

# 57. Regra para agentes de IA

Ao trabalhar em qualquer página:

1. Ler os documentos do projeto.
2. Trabalhar somente na página ou seção solicitada.
3. Não inventar informações da clínica.
4. Não alterar conteúdo validado sem solicitação.
5. Não criar novos tratamentos.
6. Não adicionar funcionalidades não previstas.
7. Utilizar assets reais quando disponíveis.
8. Priorizar mobile e performance.
9. Não alterar outras seções sem necessidade.
10. Registrar decisões novas na documentação.

---

# 58. Princípio final

O site não deverá tentar convencer o visitante utilizando quantidade de conteúdo.

A experiência deverá construir valor através da combinação de:

**imagem**

**arquitetura**

**arte**

**tecnologia**

**autoridade**

**clareza**

e então oferecer:

**contato humano.**
