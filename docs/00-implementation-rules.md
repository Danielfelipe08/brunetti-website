# Brunetti Website — Implementation Rules

## Prioridade das referências

1. `references/joia/joia-reference/JOIA-BRUNETTI-DESIGN-SYSTEM.md`
   - Fonte principal para layout, composição, animações, scroll e comportamento visual.

2. `references/joia/joia-reference/tokens.json`
   - Fonte principal para medidas, espaçamentos, tipografia, cores e timings.

3. `references/joia/visual/`
   - Usar para comparação visual durante a implementação.

4. `01-project-brief.md` até `07-visual-reference.md`
   - Usar para conteúdo, estratégia, identidade e informações da Brunetti.

5. `references/lumiere/`
   - Referência secundária. Não deve substituir o sistema visual do Joia.

## Regra principal

O site Brunetti deve reproduzir o sistema visual, composição e comportamento do site Joia, substituindo apenas conteúdo, identidade, imagens e informações pela Brunetti.

Não redesenhar componentes sem solicitação explícita.
Não alterar outras seções ao trabalhar em uma seção específica.
Implementar e validar uma seção por vez.
